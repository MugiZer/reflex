# Milestone 4 Issue 003 - Thin Localhost UI

## What to build

Build a quiet, functional localhost UI for upload, Job status polling, assembly-focused Review, and opening the generated Report.

## Acceptance criteria

- [ ] `/` shows upload and recent Jobs.
- [ ] `/jobs/:id` shows minimal status, errors, and Review/Report links.
- [ ] `/jobs/:id/review` shows one Assembly Group at a time with requested inputs and evidence summary.
- [ ] Review submission updates the Job and allows opening the Report.
- [ ] UI is colleague-usable without becoming a broad dashboard.

## Blocked by

- 001 Job API and Async Worker
- 002 Review Input and Report API
