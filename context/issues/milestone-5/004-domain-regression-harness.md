# Milestone 5-004 - Domain Regression Harness

## What to build

Add regression tests for trust-critical domain/API behavior that must not silently drift while later IFC coverage broadens.

## Acceptance criteria

- [ ] Occurrence material evidence keeps precedence over type evidence.
- [ ] Occurrence/type conflicts emit diagnostics and do not hide the conflict.
- [ ] Candidate evidence remains candidate evidence, not fixed truth.
- [ ] Blocked assemblies do not produce fake calculation snapshots.
- [ ] Low-confidence physics assemblies produce a range instead of false precision.
- [ ] Unit-normalized layer thickness is the calculation value.

## Blocked by

None - can start immediately.
