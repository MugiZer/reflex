## What To Build

Extend pure evidence extraction to include material associations, layered material evidence, non-layered material evidence, property sets, quantity sets, and candidate property evidence.

This slice turns the extractor into a useful IFC evidence machine while keeping all domain interpretation out of the parser.

## Acceptance Criteria

- [ ] Material associations are extracted from `IfcRelAssociatesMaterial`.
- [ ] Material evidence is represented by `materialStructureKind`.
- [ ] Supported material structures include `single_material`, `layer_set_usage`, `layer_set`, `constituent_set`, `material_list`, `profile_set_usage`, `profile_set`, and `unknown`.
- [ ] `IfcMaterialLayerSetUsage` evidence includes `ForLayerSet`, `LayerSetDirection`, `DirectionSense`, `OffsetFromReferenceLine`, and `ReferenceExtent`.
- [ ] `IfcMaterialLayerSet` evidence includes `MaterialLayers`, `LayerSetName`, and `Description`.
- [ ] `IfcMaterialLayer` evidence includes `Material`, `LayerThickness`, `IsVentilated`, `Name`, `Description`, `Category`, and `Priority`.
- [ ] Layer order comes from `IfcMaterialLayerSet.MaterialLayers` when present.
- [ ] Non-layered material structures are preserved as evidence, not discarded.
- [ ] Occurrence and type material evidence are both preserved when present.
- [ ] `IfcRelDefinesByProperties` psets/qsets are extracted for relevant elements.
- [ ] Type psets are extracted through `IfcTypeObject.HasPropertySets`.
- [ ] Candidate property evidence captures lambda, layer thickness, assembly thickness, material name, classification, and unit candidates.
- [ ] Lambda detection captures broad candidates but classifies strictly.
- [ ] Generic thickness properties are assembly-thickness candidates, not confirmed layer thickness.
- [ ] Numeric evidence uses raw and normalized fields, and does not silently assume units.
- [ ] Unknown units leave normalized value null and emit diagnostics.
