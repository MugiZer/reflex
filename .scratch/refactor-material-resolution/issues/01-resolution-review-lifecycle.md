# 01 - Canonical Material Resolution + Review lifecycle

**What to build:** Make Material Library, Manual, and Mixed Review choices real Job workflow decisions. One canonical Material Resolution plan should drive Review decisions, calculation inputs, provenance, Job status, and Revision creation.

**Blocked by:** None - can start immediately.

**Status:** ready-for-agent

- [ ] Recognized bilingual/noisy materials remain available as prefillable Review decisions until the user chooses a Review mode.
- [ ] Library mode applies matched values automatically and records `material_library` provenance.
- [ ] Manual mode leaves those values blank; Mixed mode fills only recognized matches.
- [ ] Unresolved materials and special physics cases still require the appropriate evidence or explicit decision.
- [ ] Submission creates a coherent completed Job and Revision without requiring manual entry for recognized library matches.
- [ ] Material Resolution, Review, calculation, and lifecycle behavior are covered through public-interface and end-to-end tests.
